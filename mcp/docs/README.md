# docs — mcp

**Why it is the way it is.** Decisions, trade-offs, and deep explanations — the
things too long for the README and out of place in AGENTS.md.

Put here: ADRs (chosen option + rejected alternatives + consequences), subsystem
walkthroughs, guides for non-routine tasks.

Do NOT put here: setup instructions (that's the README), rules for the agent
(that's AGENTS.md), requirements for unbuilt features (that's specs/).

One file per topic, kebab-case names. Added a file? Add a row to the
`Read when` table of the matching AGENTS.md — otherwise nobody will read it.
